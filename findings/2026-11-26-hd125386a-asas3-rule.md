# Rule (written before any ASAS-3 data was fetched): ASAS-3 timing test of HD 125386A

MV2, Munim, Inc. Made with AI agents working in his name; no human expert has checked it yet.
Text CC BY 4.0. Written 2026-11-26 ~12:20 UTC, after the blind Gaia DR3 SB1 search (job
g8-dr3-sb1-v1) flagged HD 125386A = Gaia DR3 5854558019550047872 and after catalogue vetting found it
listed as eclipsing nowhere, but **before** the ASAS-3 light curve was downloaded or looked at.

## Inputs (Gaia DR3, nss_two_body_orbit, SB1)
- P = 3.6734168627 +- 0.00016819 d; t_periastron = -0.5645021 +- 0.8405 d (Gaia time = BJD - 2455197.5,
  orbit reference 2191.5 + t_periastron); e = 0.0158 +- 0.0199; omega = 301.405 +- 82.3 deg;
  K1 = 48.48 +- 1.11 km/s; f(m) = 0.0433 Msun.
- Conjunction 0 (visible star behind its companion, true anomaly 90 deg - omega = 148.595 deg):
  mean anomaly 147.644 deg (hand: M = nu - 2e sin nu + 0.75 e^2 sin 2nu), phase 0.41012 after
  periastron -> **T0 = Gaia 2192.44204 = HJD' 7389.94204** (HJD' = HJD - 2450000 = Gaia + 5197.5).
  Conjunction 1: phase 0.91535 -> Gaia 2194.29796.
- Gaia's own four faint G epochs (depth >= 0.044 mag) all fall at conjunction 0 (dphase +0.013,
  +0.017, -0.013, -0.003); none at conjunction 1. T0's own uncertainty is set by the eclipses, not
  by t_periastron's large formal error (e and omega are poorly constrained for this near-circular orbit).

## Data
ASAS-3 V light curve, ID 142119-6138.9 (from the Gaia J2000 position 215.32952 -61.648862),
grades A and B only, aperture MAG_3 (V ~ 9.5). Points fainter than median + 0.40 mag are dropped as
bad frames before anything else (expected single-epoch depth <= ~0.25 mag in V).

## Test (fixed)
1. Median V of the kept points; **faint = V >= median + 0.07**.
2. For each faint point: n = round((t - T0) / P), phi = (t - T0 - n P) / P in [-0.5, 0.5).
3. **Test A:** fraction of faint points with |phi| <= 0.12. Chance (one window, uniform phase) = 0.24.
   Window reasoning: Gaia's 1-sigma period error carried back 600-1,500 cycles is 0.03-0.07 in
   phase, plus the eclipse half-width (~0.025 for a ~0.18 d eclipse).
4. **Pass = at least half of the faint points in the window AND one-sided binomial p < 1e-4.**
5. Reported, not graded: the faint points near phi = 0.5 (secondary eclipse), the median phi,
   and a hand linear fit of O-C against n for the in-window points (a period correction, which must
   lie within +-3 sigma = +-0.0005 d of Gaia's P to be called consistent).
If the ASAS-3 server returns no data for this ID, the test is not run and nothing is concluded.
