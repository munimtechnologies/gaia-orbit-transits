# TIC 93622019: a reproducible 95% companion-mass bound from Gaia DR3's own radial velocities (exploratory)

## Why this check

TIC 93622019 (Gaia DR3 5345417757181174144, an F star of G = 12.57 at about 600 pc) shows a 1.28%
deep (deblended) transit every 2.1238933 d in TESS. This project found that period on 22 Nov; Gaia
DR3 had listed the star as a transit candidate at a 2.83-day alias. On 24 Nov a pre-registered test
showed that Gaia's own photometry dims at the TESS ephemeris (S/N 5.6, empirical p 0.001), so the
dip is on the target at Gaia's resolution (`findings/2026-11-24-vpt-epochs-box-results.md`). The
most common false positive left is an eclipsing companion star on the same orbit: a small star
grazing a bigger one, or a low-mass star that looks like a planet in size. Such a companion would
pull the F star around at tens of km/s. Gaia measured the star's radial velocity 27 times.

Nobody has published radial velocities of this star (ExoFOP: no TOI, CTOI, spectra or notes, read
24 Nov; web search for both identifiers found nothing).

**What this note adds to our own earlier estimate.** `findings/2026-11-22-vpt-pf-dr3-results.md`
already gave a rough hand estimate from the same Gaia fields (K below about 10 km/s, companions
above about 0.08-0.1 Msun excluded). This note replaces it with code and tests, adds a one-sided 95%
bound from the chi-square distribution and the inclination limit from the transit geometry, and
saves the Gaia row in the repository. The conclusion does not change; the number is now
reproducible.

## Data

| Gaia DR3 field | value |
|---|---|
| rv_method_used | 1 (median of the epoch velocities; epoch statistics valid for grvs_mag <= 12) |
| grvs_mag | 11.96 |
| rv_nb_transits | 27 |
| radial_velocity | -4.90 km/s |
| radial_velocity_error | 1.684 km/s |
| rv_chisq_pvalue | 0.514 (constant velocity is a good fit) |
| rv_renormalised_gof | 4.10 |
| rv_amplitude_robust | 16.2 km/s peak to peak (after Gaia's outlier filter) |
| ruwe / ipd_frac_multi_peak / non_single_star | 0.90 / 0 / 0 |

By the criterion of Katz et al. (2023, A&A 674, A5), a star is RV-variable when rv_chisq_pvalue
<= 0.01 and rv_renormalised_gof > 4. This star is not (p = 0.51).

## Method

For rv_method_used = 1, radial_velocity_error = sqrt(sigma_med^2 + 0.11^2) with sigma_med =
sqrt(pi/2) sigma / sqrt(N) (Katz et al. 2023; applied the same way in arXiv:2401.11293). So the
scatter of the 27 epoch velocities is sigma = sqrt((2N/pi)(err^2 - 0.11^2)) = **6.97 km/s**. We make
the most conservative assumption: all of that scatter is orbital motion, none is noise. A circular
orbit sampled at random phases has scatter K / sqrt(2), so K <= 9.85 km/s. With the chi-square
distribution for 26 degrees of freedom, the one-sided 95% upper bound on the scatter is 9.06 km/s,
so **K <= 12.8 km/s (95%)**. Converting K to a companion mass uses the TIC mass of the star
(1.33 Msun), the TESS period, and sin i >= 0.980, the smallest inclination that still lets a body of
the measured size cross the star (a = 7.65 Rsun = 5.6 stellar radii).

## Result

| quantity | value |
|---|---|
| epoch scatter (all of it taken as signal) | 6.97 km/s |
| K, best estimate of the upper limit / 95% bound | 9.85 / 12.8 km/s |
| companion mass, upper limit / 95% bound | 80 / **105 Jupiter masses (0.10 Msun)** |
| K an equal-mass twin would cause | 115 km/s |
| K a 0.3 Msun M dwarf would cause | 36 km/s |
| companion radius from the deblended depth | 1.50 Jupiter radii |

**Whatever transits TIC 93622019 every 2.124 d is less massive than about 0.10 Msun (95%).** Gaia's
velocities rule out an eclipsing binary made of the F star and any companion above the bottom of
the main sequence. With the 1.5 Jupiter-radius size, what remains is a hot Jupiter (an inflated one
is common around F stars at this period), a brown dwarf or very-low-mass star near 0.08-0.10 Msun
(old ones are only about 0.8-1.1 Jupiter radii, so they would need a grazing geometry to make this
depth), or a blend with an eclipsing pair unresolved by Gaia that the F star dilutes. The Gaia
astrometry shows no sign of a resolved or wobbling companion (RUWE 0.90, no multi-peak images), but
that does not exclude a bound pair closer than about 0.1 arcsec.

## Limits

- The scatter comes from Gaia's summary statistics, not from the 27 individual velocities (Gaia DR3
  did not publish epoch RVs). The formula holds for rv_method_used = 1, which applies here.
- Taking all scatter as signal makes the bound conservative. Gaia's own fit says the velocities are
  consistent with constant, so the real K is likely much smaller; only spectroscopic follow-up can
  measure it.
- An eccentric orbit would change the K-scatter relation; at 2.1 d tidal circularisation makes a
  circular orbit likely, but it is assumed.
- The stellar mass is the TIC value; a 10% change in it changes the mass bound by about 7%.
- This does not make TIC 93622019 a planet. It is still a candidate, now with one standard false
  positive (a stellar-mass companion on the transit period) excluded.
