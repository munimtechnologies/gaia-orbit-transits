## Deviation from the pre-registration
- p0 was to be the fraction of all 619 good points inside the window. Computing 619 phases by hand was
  not feasible, so p0 = 0.07 (the window width) is used, which assumes uniform phase coverage; with 619
  points over 3,250 days and a 7.25 d period this is a close approximation, and the result is far from
  any threshold either way.

## Verdict
INCONCLUSIVE, as the pre-registration defined for an A1 failure. ASAS-3 neither confirms the TESS eclipse
in 2000-2009 nor decides between the TESS and Gaia periods. A 4.1% eclipse is about the size of one
ASAS-3 point's error here (0.035-0.05 mag), so this test had low power; it is not evidence against the
eclipse. The star stays a candidate pending the queued TESS pixel test (tier2-pixvet-v1). Nothing is
claimed from this test.

## Lesson
For eclipses shallower than ~1.5x the per-point error, faint-point counting in ASAS-3 is too weak;
use a mean-depth (in-window minus out-of-window) test over all points, which needs a compute job.
