# Rule (written before any ASAS-3 data was fetched): ASAS-3 timing test of TYC 1316-1554-1

g8-dr3-sb1-v1) flagged TYC 1316-1554-1 = Gaia DR3 3350075697770930304 and after catalogue vetting

## Inputs (Gaia DR3 nss_two_body_orbit, SB1)
- P = 1.6262843323 +- 1.4e-5 d; t_periastron = -0.75433423 d (Gaia time = BJD - 2455197.5, orbit
  reference 2191.5 + t_periastron); e = 0.0776122; omega = 153.4343 deg; K1 = 95.20 km/s;
  f(m) = 0.1441 Msun. G = 10.580, BP-RP = 0.721. RA 88.149251, Dec +17.688585.
- Conjunction 0 (visible star behind its companion, true anomaly 90 - omega = 296.5657 deg):
  by hand E = -59.5205 deg, M = E - e sin E = -0.971940 rad, phase 0.845311 after periastron ->
  **T0 = Gaia 2192.12038 = HJD' 7389.62038** (HJD' = HJD - 2450000 = Gaia + 5197.5).
- Conjunction 1 (true anomaly 270 - omega = 116.5657 deg): E = 112.5136 deg, M = 1.892035 rad,
  phase 0.301127 after periastron -> **conjunction 1 at phase D1 = 0.45582 after conjunction 0**.
- Gaia's own five faint G epochs: three at conjunction 0 (depth 0.031, 0.102, 0.101 mag; dphase
  +0.022, -0.014, -0.024) and two at conjunction 1 (0.044, 0.029 mag; dphase +0.029, +0.010).
  So Gaia already suggests a primary eclipse ~0.10 mag deep in G and a secondary ~0.04 mag.

## Data
ASAS-3 V light curve, ID 055236+1741.3 (or the ASAS ID that the server returns for this position;
the block whose designation matches is used, other blocks are only a cross-check). Grades A and B
only. Aperture fixed now as **MAG_2** (ASAS-3 guidance for V ~ 10-11; Gaia G 10.58 and
BP-RP 0.72 give V ~ 10.8), whatever the data look like. Points
fainter than median + 0.50 mag are dropped as bad frames before anything else.

## Test (fixed)
1. Baseline = median MAG_2 of the kept points; sigma = 1.4826 x median absolute deviation.
   **faint = V >= baseline + max(0.07, 3 sigma)** (the star is ~1.7 mag fainter than HD 125386A, so
   the noise floor is allowed to set the threshold).
2. For each faint point: phi = ((t - T0) / P) mod 1, in [0, 1).
3. **Two windows**: conjunction 0 (|phi| <= 0.08, wrapping at 1) and conjunction 1
   (|phi - 0.45582| <= 0.08). Chance for uniform phases = 0.32. Window reasoning: Gaia's
   1-sigma period error carried back ~1,900-3,400 cycles is 0.016-0.029 in phase, plus an eclipse
   half-width of ~0.04 in phase for a 1.63-day detached pair.
4. **Pass = at least half of the faint points in the two windows AND one-sided binomial p < 1e-4.**
5. Reported, not graded: how many in-window faint points sit at conjunction 0 vs 1 (which eclipse
   is deeper in V), the median phi of each group, and a through-origin fit of O-C vs cycle for the
   conjunction-0 points (a period correction; consistent if within +-3 sigma = +-4.2e-5 d).
If the ASAS-3 server returns no data or fewer than 100 A/B points for this star, the test is not
run and nothing is concluded.
